# Texture Mixer Mod

Texture Mixer Mod is a Minecraft mod that allows players to import and mix texture packs in-game. With this mod, you can import multiple texture packs, categorize them, and create custom mixed textures. The mod includes a user-friendly interface for easy navigation and texture mixing.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded.

## Use

1. Launch Minecraft and load a world.
2. Press the `I` key to open the Texture Mixing menu.
3. Use the menu to import texture packs and navigate through different categories.
4. Select the textures you want to mix and click the "Mix Textures" button to create a custom texture.
5. The mixed texture will be displayed in the menu for preview.
